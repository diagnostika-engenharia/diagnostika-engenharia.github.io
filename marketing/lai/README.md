# marketing/lai/ — Solicitações via Lei de Acesso à Informação

Destrava o gargalo de dados oficiais para o CSV de condomínios. Sem isso, a base fica limitada a curadoria manual (portal por portal) e cresce devagar.

## Arquivos
- **[pedido-padrao.md](./pedido-padrao.md)** — texto único, substituir `[CIDADE]` para cada uma das 7 prefeituras.
- **[prefeituras.md](./prefeituras.md)** — canais (e-SIC ou presencial) + destinatário sugerido de cada uma.

## Como usar
1. Copiar `pedido-padrao.md` para 7 arquivos ou 7 abas do Sheets.
2. Substituir `[CIDADE]` e completar dados do solicitante.
3. Enviar todas no mesmo dia (uniformiza prazos e follow-up).
4. Registrar o número de protocolo de cada uma em `condominios-rmc.csv` como coluna adicional se quiser rastreio.

## Prazo legal
20 dias corridos (Lei 12.527/2011, Art. 11). Prorrogáveis por mais 10 com justificativa.

## Custo
Zero — LAI é gratuita.
