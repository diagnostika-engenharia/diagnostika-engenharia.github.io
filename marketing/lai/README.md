# marketing/lai/ — Solicitações via Lei de Acesso à Informação

Destrava o gargalo de dados oficiais para o CSV de condomínios. Sem isso, a base fica limitada a curadoria manual (portal por portal) e cresce devagar.

## Arquivos
- **[campinas.md](./campinas.md)** · **[valinhos.md](./valinhos.md)** · **[vinhedo.md](./vinhedo.md)** · **[paulinia.md](./paulinia.md)** · **[sumare.md](./sumare.md)** · **[hortolandia.md](./hortolandia.md)** · **[indaiatuba.md](./indaiatuba.md)** — 7 pedidos prontos para copiar/colar.
- **[pedido-padrao.md](./pedido-padrao.md)** — template base (usado pelo gerador).
- **[prefeituras.md](./prefeituras.md)** — canais (e-SIC ou presencial) + destinatário sugerido de cada uma.
- **[../scripts/gerar-lai.js](../scripts/gerar-lai.js)** — regera os 7 arquivos a partir da config (rodar com `node`).

## Como usar
1. Abrir o arquivo da cidade correspondente (ex.: `campinas.md`).
2. Copiar o CORPO do pedido (entre os separadores).
3. Colar no e-SIC (link no topo do arquivo) ou enviar por e-mail à Ouvidoria.
4. Preencher seus dados no final antes de enviar.
5. Anotar o número de protocolo retornado.
6. Enviar as 7 no mesmo dia (uniformiza prazos e follow-up).

## Prazo legal
20 dias corridos (Lei 12.527/2011, Art. 11). Prorrogáveis por mais 10 com justificativa.

## Custo
Zero — LAI é gratuita.
